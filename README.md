# Library Book Program

**CIS 199 – Software Development I | C# Console Application**

## Project Overview
Developed a C# console application that uses a reusable LibraryBook class to store and manage book information, including prices, page counts, borrowing history, and availability.

## Features
- Creates and stores book objects in an array.
- Uses constructors, properties, and methods to manage book data.
- Validates numerical values and applies default values when necessary.
- Displays book information before and after updates.

## Skills Demonstrated
C# · Object-Oriented Programming · Classes · Encapsulation · Constructors · Properties · Arrays · Data Validation
